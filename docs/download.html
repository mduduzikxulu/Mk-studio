⚠️ Server required

The video downloader needs the Studio Python server (app.py) running locally on your machine. It cannot run on GitHub Pages because it requires a backend to fetch videos.

To use it, clone the repo, install dependencies (pip install -r requirements.txt), and run python app.py.

Paste or type a full URL to fetch the video.
